# 🎀 Barbie School

Modern School Management Web App built with HTML, CSS, JavaScript and JSON.

## Run
Open `index.html` in a browser or deploy the whole folder to GitHub Pages.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for the Pages URL.

> Note: The app loads JSON with `fetch()`. It works normally on GitHub Pages because the site is served over HTTP(S). Opening `index.html` directly as a `file://` URL may prevent JSON loading in some browsers.
